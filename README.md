# YouTube Clone 🎬

A very simple YouTube clone built using only **HTML** and **CSS**.  
This project focuses on practicing layout, styling, and responsive design.

## 🚀 Features
- Static homepage with video thumbnails
- Navigation bar similar to YouTube
- Responsive design using CSS Flexbox/Grid
- Purely front-end (no JavaScript or backend)
